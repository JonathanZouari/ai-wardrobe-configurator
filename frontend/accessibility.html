מחויבות לנגישות

אנו רואים חשיבות רבה בהנגשת האתר לאנשים עם מוגבלות, כדי לאפשר לכל אדם לעצב ולהזמין ארון בעצמאות, בשוויון ובכבוד, בהתאם לחוק שוויון זכויות לאנשים עם מוגבלות ולתקנות הנגישות לשירות.

רמת ההנגשה

האתר הונגש בהתאם לתקן הישראלי ת"י 5568 חלק 1, המבוסס על הנחיות WCAG 2.0 של ארגון W3C, ברמה AA.

מה הונגש באתר

  • קישור "דלג לתוכן הראשי" בתחילת כל עמוד.
  • סימון בולט של הרכיב שבפוקוס בעת ניווט במקלדת.
  • מבנה עמודים עם כותרות ואזורים מסומנים (כותרת עליונה, ניווט, תוכן ראשי, כותרת תחתונה).
  • טקסט חלופי לתמונות בעלות משמעות; תמונות דקורטיביות מסומנות כך שקוראי מסך מדלגים עליהן.
  • כיבוד הגדרת המערכת "הפחתת תנועה".
  • תפריט נגישות (הכפתור העגול בפינה התחתונה של כל עמוד).

אופן השימוש בתפריט הנגישות

לחצו על כפתור הנגישות בפינה התחתונה של המסך, או הגיעו אליו במקש Tab ולחצו Enter. בתפריט ניתן:

  • להגדיל ולהקטין את גודל הטקסט (עד 160%).
  • להפעיל ניגודיות גבוהה, גווני אפור, הדגשת קישורים, גופן קריא, ריווח טקסט, עצירת אנימציות וסמן גדול.
  • לאפס את כל ההגדרות.

מקש Escape סוגר את התפריט. ההגדרות נשמרות בדפדפן במכשיר זה בלבד.

חלקים שאינם נגישים במלואם

  • תצוגת התלת־ממד של הארון היא תמונה גרפית שקוראי מסך אינם יכולים לתאר. המידות, החומרים וסוג הארון ניתנים לקביעה גם בשדות ובכפתורים שליד התצוגה.
  • עוזר העיצוב הקולי דורש דיבור. אותו עוזר זמין גם בהקלדה.
  • עורך החלוקה הפנימית ופעולות הגרירה בתצוגה טרם נבדקו במלואם בהפעלה באמצעות מקלדת וקורא מסך.
  • ממשק האתר זמין כרגע באנגלית בלבד.

אם נתקלתם בחלק שאינו נגיש, נשמח לקבל את העיצוב או לטפל בבקשה בטלפון או בדוא"ל (פרטים בהמשך).

Accessibility statement

Last updated: 26 November 2026

Standard

This site was made accessible according to Israeli Standard 5568 Part 1, which is based on the W3C Web Content Accessibility Guidelines (WCAG) 2.0, level AA.

What has been made accessible

  • A "Skip to main content" link at the start of every page.
  • A clearly visible focus indicator when navigating with the keyboard.
  • Headings and labelled page regions (header, navigation, main content, footer).
  • Text alternatives for meaningful images; decorative images are hidden from screen readers.
  • The operating system's "reduce motion" setting is respected.
  • An accessibility menu (the round button in the bottom corner of every page).

Using the accessibility menu

Select the accessibility button in the bottom corner, or reach it with Tab and press Enter. The menu lets you enlarge or reduce text (up to 160%), turn on high contrast, grayscale, highlighted links, a readable font, wider text spacing, stopped animations and a large cursor, and reset everything. Escape closes the menu. Settings are kept in this browser on this device only.

Known limitations

  • The 3D wardrobe view is graphical and cannot be described by screen readers. Size, materials and wardrobe type can also be set with the fields and buttons next to the view.
  • The voice design assistant needs speech. The same assistant also works by typing.
  • The interior layout editor and drag actions in the view have not yet been fully tested with keyboard-only use and screen readers.
  • The interface is currently available in English only.
